# Contributing to This Repository

Thanks for your interest in contributing! Here's how you can help.

## How to Contribute

1. **Fork** the repository and create a new branch from `main`.
2. **Make your changes** — keep commits focused and descriptive.
3. **Open a Pull Request** with a clear title and description of what you changed and why.

## Reporting Issues

- Use [GitHub Issues](https://github.com/MithunKumarRajak/MithunKumarRajak/issues) to report bugs or suggest improvements.
- Include screenshots or logs if applicable.

## Guidelines

- Keep changes minimal and focused on one thing at a time.
- Follow existing code style and formatting conventions.
- Write clear, descriptive commit messages (e.g., `fix: correct broken stats card URLs`).

## Larger Changes

For significant changes (new sections, layout overhauls, etc.), please **open an issue first** to discuss the proposal before submitting a PR.

---

Thank you for contributing! 🙌
